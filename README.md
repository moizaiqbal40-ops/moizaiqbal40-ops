## 🚀 Featured Projects

### 🎨 AI Virtual Painter
**Real-time touchless drawing using hand tracking.**

Built around **Python + OpenCV + MediaPipe**, using hand landmarks and gestures to turn a webcam into an interactive canvas.

**Highlights**
- Real-time hand tracking
- Gesture-based drawing controls
- Colour palette interaction
- Drawing / erasing workflow
- Undo / redo
- Shape fitting
- Visual feedback and effects

[![View Project](https://img.shields.io/badge/VIEW%20PROJECT-111827?style=for-the-badge&logo=github)](https://github.com/moizaiqbal40-ops/ai-virtual-painter)

---

### 🤟 Ishara — PSL Sign Language Translator
A computer-vision project focused on translating **Pakistan Sign Language / Urdu alphabet gestures** into readable output.

**Engineering focus**
- MediaPipe hand landmarks
- Geometric gesture classification
- Confidence scoring
- Temporal smoothing / debounce
- Transcript building
- Text-to-speech
- Accessibility-first interaction

> A project where the goal isn't just detection — it's making computer vision useful to a real person.

---

### 🧠 MindEase
A conversational mental-wellbeing chatbot project built as a practical exploration of **Python + Streamlit + conversational UX**.

**Focus:** simple interface, user interaction, and turning an idea into a usable prototype.

---

### 🎵 Mood-Based Music Website
